# Sistem Pengurusan Kenderaan Jabatan

Starter UI menggunakan Vanilla HTML + CSS + JavaScript.

## Struktur
- `index.html` — Dashboard
- `pages/` — modul sistem
- `css/` — stylesheet
- `js/` — logic frontend
- `assets/` — aset

## Fasa seterusnya
1. Finalkan UI Dashboard
2. Bina modul Kenderaan
3. Bina modul Pemandu + Pemandu Gantian
4. Bina Permohonan berdasarkan borang rasmi
5. Bina Perjalanan + view mengikut pemandu/kenderaan
6. Sambungkan Supabase Auth, Database, Storage dan RLS
7. GitHub + Cloudflare Pages
